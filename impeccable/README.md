# newfea：NexFlow 面包盘点（本地后端 + 前端）

双击 `start.bat`，几秒后浏览器自动打开 http://127.0.0.1:8100
黑色窗口就是后端，开着页面就能用；关掉黑色窗口，服务就停了。

## 结构
| 文件 | 作用 |
|---|---|
| `app.py` | 后端：FastAPI 载入 `weights/best.pt`，在你电脑上跑 YOLO；同时提供前端页面 |
| `static/index.html` | 前端：选样图或上传照片 → 画框 → 店员改数量 → 确认；右边是会互动的小怪兽 |
| `weights/best.pt` | 你训练的 bread_finetune 模型（15 个品种） |
| `demo_images/` | 5 张原尺寸样图，文件名是真实数量 |
| `confirmed/` | 每次确认的记录（JSON） |
| `web_online/` | 之前的纯浏览器版本，留作备份 |

## 小怪兽会做什么
- 眼睛跟着鼠标转，鼠标停在样图上时会看那张图
- 识别时上下晃，盯着图片；数完会说结果
- 有低置信度的框时会皱眉，提醒你核对
- 确认后开心扭动；搓它或点它会说话

## 换东西
- 换模型：覆盖 `weights/best.pt`
- 换样图：把 jpg/png 放进 `demo_images/`，刷新页面
- 端口 8100 不变，NexFlow 盘点页的“拍照盘点 / 用样图盘点”也连这里

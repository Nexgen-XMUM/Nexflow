## 2. 这些变化意味着什么

队友新版布局、主题、侧栏、导览和手机展示继续沿用；CSS 规则与基线一致。
录入页只取 `/api/products` 的 ID、名称、别名、库存，包装图标仅作装饰。
没有来源的中文名、目录成本、目录原价和食物重量展示已移除。

已读取 `/api/inventory` 的实际响应：它提供售价和库存，没有成本。
录入页不需要售价，因此保留带别名的商品查询，不增加第二次查询或扩大响应。
生成结果直接使用后端 `items`、`totals`、`promo.text`、`carbon`、`warnings`；前端只格式化展示金额。

看板展示最近一次报价的全部售出情景金额、CO₂e 估算与商品件数。
数量变化或新请求失败会清空失效报价，模拟批准只增加本页广播次数。
生成期间锁定录入、重置和重复提交；切页后，返回结果不会强制抢回页面。

### 启动与亲自验证

在仓库根目录运行，环境变量只影响该进程：

```bash
AI_PROVIDER=local_demo DEEPSEEK_API_KEY='' .venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8765
```

打开 <http://127.0.0.1:8765/app>，在 Butter Croissant 一行填 `10`，提交后即可看到单品验证行的结果和本地文案。
快速输入 `10 croissants, 2 chocolate slices, 1 sourdough`，先点“识别”再提交，可复现多品结果。
验证后在运行服务的终端按 Ctrl+C 关闭。

复现自动检查：

```bash
AI_PROVIDER=local_demo DEEPSEEK_API_KEY='' .venv/bin/python -m pytest backend/tests -q
node --test frontend/tests/*.test.cjs
```

前端映射测试使用现有 `.venv` 中的 TestClient，无需启动服务或安装 Node 依赖。
更完整的错误输入与断线操作说明见 [前端启动说明](../../frontend/README.md)。

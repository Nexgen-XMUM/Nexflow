## 四、需要明确交代的问题

| 问题 | 影响 | 处理顺序 |
|---|---|---|
| 购买模块和账户接口还没接入 | 不能宣称顾客购买取餐、积分全流程已完成 | 优先取得实际交付和接口 |

| PR尚待团队审查合并 | 合并前队友仅拉main看不到整合结果 | 获取整合分支或源码包；按团队流程审查PR |
| 真实时间服务有营业窗口 | 白天直接运行普通服务可能无法演示下单或捐赠清算 | 比赛用 desktop_demo；重启服务后刷新网页读取新时钟 |
| 角色只是页面演示分工 | 不代表已实现正式登录认证；付款、广播和交接均需按演示口径介绍 | 比赛讲解明确模拟边界，不扩展生产功能 |

本轮最终结果：后端272项通过，前端31项通过。本机浏览器已实走盘点、老板模拟审批、复制促销、独立样本计算、模拟捐赠交接、看板刷新、旧路由跳转、失败恢复；截图示例为已交接10件、CO₂e估算2kg、收入RM0，本次预计清仓RM30。

接手建议：

1. 解压ZIP，在自己的电脑按 quickstart 启动，先确认现有捐赠路线。
2. 购买负责人提供本轮模块与账户接口，明确其是否由prog负责；不要拿已关闭的旧PR #20代替交付。
3. 确认购买模块是否复用已登记批次，挂接购买、取餐和唯一积分余额。
4. 补购买取餐验收，并在队友电脑重走已完成的捐赠路线；记录订单/捐赠ID与统计变化。
5. 在比赛电脑排练三分钟并录屏，按团队流程审查本轮本地改动。

采购预测、自动社交平台发布、真实WhatsApp发送均属后续范围，不属于当前缺陷；真实支付、完整登录和碳交易也没有作为本轮目标实现。

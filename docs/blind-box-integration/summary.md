## 2. 实际验证与使用方式

清仓仍使用后端金额、CO₂e 和 `promo.text`，保留数量校验、重复请求拦截、失败清空与来源标注。
盲盒只读取独立批次并计算，前端仅将整数 sen 转为 RM；不调用订单、核销、捐赠交接或积分兑换接口。
机构与消费者均为演示；候选互为替代，计算结果不表示库存已预留。

| 验证 | 实际结果 |
|---|---|
| 后端全部测试 | 253 passed；1 项现有 Starlette/httpx 弃用提醒 |
| 前端全部测试 | 14 passed，0 failed，0 skipped |
| 清仓浏览器流程 | 10 牛角包：原价60、成本20、清仓30、毛利10、CO₂e 2 kg；本地文案 |
| 盲盒有方案 | 商品名称可读；示例售价 RM7.00、RM9.60、RM4.40 |
| 盲盒无方案 | `wheat` 筛选显示拒绝原因、余料统计、后端演示捐赠机构 |
| 生物能源分流 | 规划日期超过安全截止后显示期限拒绝与能源估算，未更改机器时间 |
| 空库存 | 新临时数据库显示空库存及无可用建议，不挪用清仓库存 |
| 请求失败及恢复 | 关闭服务后旧建议清空、错误可见、按钮恢复；重启后可再次计算 |
| 消费者演示 | 浏览器显示独立积分规则；自动测试确认兑换不请求后端 |
| 数据与服务清理 | 14 个受保护文件哈希不变，含 `.env` 与共享数据；临时服务及数据库已关闭、清理 |

接口映射测试通过 TestClient 获取真实响应，覆盖捐赠、能源、空库存及候选，并确认计算不改变库存。
清仓多商品、非法数量、模型来源标签和异步状态通过自动回归；本轮浏览器清仓实走为单商品。
全部验证强制 `local_demo`；模型成功/回退标签使用模拟响应，不消耗模型额度。

亲自运行见 [前端启动与验收说明](../../frontend/README.md)：先启动临时数据库服务，打开 `/app`。
盲盒首次为空，明确调用 `/demo-seed` 后刷新即可；真实时间、定时清算和安全期限仍会影响可用库存。
